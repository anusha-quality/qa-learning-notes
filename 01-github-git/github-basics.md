# GitHub & Git Basics

## What is Git?

Git is a version control system.

It helps us track changes made to our files.

Example:

I create a test case today.

Tomorrow I modify the test case.

Git helps me know:
- What changed
- When it changed
- What the previous version looked like

---

## What is GitHub?

GitHub is a platform where Git repositories can be stored online.

Git = tracks changes

GitHub = stores and shares the Git repository online

---

## Important Terms

### Repository (Repo)

A repository is a project folder managed by Git.

Example:

qa-learning-notes

---

### File

A file contains our actual work.

Examples:

- testing-basics.md
- practice.sql
- README.md

---

### Commit

A commit is like saving a checkpoint of our work.

Example:

"Add SQL JOIN notes"

---

### Push

Push means sending our local Git changes to GitHub.

---

### Pull

Pull means getting the latest changes from GitHub.

---

### Branch

A branch is a separate version of the project where we can work without disturbing the main version.

---

### Clone

Clone means downloading a GitHub repository to our computer.

---
